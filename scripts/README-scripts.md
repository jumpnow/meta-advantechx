# README-scripts.md

The Advantech iMX8ULP ROM2620 dev board can boot from eMMC or sd card.

There are scripts here to prepare either boot media with the archives
generated from the Yocto build.

The uuu.sh script is for the eMMC and requires the NXP uuu utility.

These three scripts are for SD card preparation

* mk2parts.sh
* copy\_boot.sh
* copy\_rootfs.sh
